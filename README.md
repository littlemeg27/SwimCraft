# SwimCraft

iOS swimming companion built as the Full Sail University Computer Science capstone (Project and Portfolio VI).

SwimCraft helps swimmers log workouts, review sets, and keep training data in one place on iPhone.

## Features

- Workout logging and review
- Swim-focused training views
- Custom color system and UI mockups
- Capstone pitch, screenshots, and walkthrough assets in-repo

## Tech stack

| Layer | Tools |
|---|---|
| Language | Swift |
| Platform | iOS |
| Health | HealthKit (swim / workout data) |
| UI | Native iOS |

## Project status

Capstone complete. Source lives in `SwimCraft/SwimCraft`. Design and presentation files are in `Mock Up`, `Colors`, `Workouts`, and the project pitch PDFs.

## Getting started

1. Clone the repo
2. Open the Xcode project inside `SwimCraft/`
3. Select an iPhone simulator or device
4. Enable HealthKit capabilities if prompted
5. Build and run

```bash
git clone https://github.com/littlemeg27/SwimCraft.git
```
